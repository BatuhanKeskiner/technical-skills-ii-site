How it is organised

NN-slug/One folder per week. content.js is the week's manuscript (the only file that is written), assets/ its pictures, files/ the PDFs handed out, notes/ the exported batches.
00-catalogue/The eleven layouts, each shown at its least and its most. Look here before asking for a new one.
CONTRACT.mdThe rulebook: the layouts, the block types, the rules. Every session that writes a week reads it first.
CLAUDE.mdStanding instructions for Claude Code in this folder.
_shared/The machine: one stylesheet, the fonts, the renderer, the page shell, the two correction modes, the interactives, the week template. Never edited by hand.
_shared/tools/make-student-copy.py writes one self-contained file per week into _student/; check-pages.py screenshots every page and reports anything that overflows.

Authoring a week. Content lives in content.js, plain data, no markup, written against CONTRACT.md. Every page names its layout and carries a title. If a piece of content has no layout or block type, it is reported, not invented: it gets added once, to _shared and the catalogue, and every week gains it.
